# EmptyOS (`Empty`)

> A minimal, custom bare-metal operating system written in C and x86 Assembly.

---

## About the Project
`EmptyOS` is a low-level OS built completely from scratch. No third-party bloat, no heavy layers—just pure, close-to-the-metal C execution, a custom boot pipeline, and core hardware interaction.

- **Kernel Language:** C
- **Architecture:** x86 / Bare-Metal
- **License:** GPLv3
- **Current Status:** Active Testing & Development

---

## Testing & Contributions
This project is currently open for active testing! 

If you are running tests:
1. Build and launch using QEMU (`make run`).
2. Log any hardware initialization issues, memory crashes, or unexpected interrupt behaviors under the **Issues** tab.
3. Check back regularly for updated kernel pushes!
